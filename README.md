# Garrafa Térmica Trity 2 — Landing Page

Landing Page responsiva e de alta conversão para a **Garrafa Térmica Trity 2** da Get.

## Tecnologias e Recursos
- **100% CSS Puro**: totalmente compatível com VTEX (zero dependência de scripts JavaScript).
- **Mosaico com Rolagem Horizontal**: carrossel com scroll interativo e modal lightbox integrado.
- **Visual Apple-Style**: cards arredondados, animações suaves e tipografia moderna.
- **Assets Otimizados**: imagens compactadas para alta performance e carregamento rápido.
